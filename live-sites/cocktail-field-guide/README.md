## Overview

Cocktail Field Guide is a lightweight personal web project designed as a digital cocktail menu and visual reference. The interface combines structured cocktail information with a vintage-inspired, late-night editorial aesthetic.

The site currently includes a curated collection of 70+ classic and modern cocktails, organized by popularity and searchable across names, spirits, ingredients, flavors, and occasions.

## Key Features

- **Bilingual interface** with a Chinese-English mixed version and a fully English version
- **70+ cocktail recipes** with ingredients, preparation methods, glassware, garnish, flavor profiles, and recommended occasions
- **Popularity-based ordering**, with more widely recognized cocktails appearing earlier in both the main menu and search results
- Multi-dimensional filtering by:
  - Base spirit
  - Flavor
  - Occasion
- **Random cocktail selector** for deciding what to drink
- Expandable **More Filters** for less common spirits and flavor profiles
- Detailed cocktail views with visual flavor ratings
- Custom minimalist cocktail illustrations for different glass styles
- Responsive layout for desktop and mobile
- Scroll-triggered animations and subtle interactive transitions

## Design

The visual direction combines:

**Art Deco cocktail menu × midnight editorial × scrapbook / pinned-note collage**

Cocktails are presented as irregular paper notes attached to a dark night-board using pins and translucent tape. Muted blue, teal, violet, rose, and gray paper tones blend into the nighttime palette, while decorative serif typography, hand-drawn flourishes, stars, and fine-line ornaments add an illustrated editorial character.

## Tech Stack

- HTML
